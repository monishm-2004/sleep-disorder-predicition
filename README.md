The aim of this project is to detect the presence of a sleep disorder based on data derived from an individual's lifestyle and health parameters. The "Sleep Health and Lifestyle Dataset " has been imported from kaggle, containing information like age, gender, occupation, sleep duration, quality of sleep, physical activity, stress level, BMI, blood pressure, heart rate, and daily steps. By analysing these parameters , the goal is to build a machine learning model that can most accurately predict the sleep disorder a person is suffering from.

Required Libraries (Not required to download if running on collab)
pandas — for data handling
numpy — for numerical computations
matplotlib & seaborn — for data visualization
scikit-learn — for machine learning models
xgboost — for gradient boosting classification.
